# 🚀 .NET Advanced: Course Exercises
This repository contains my laboratory exercises and projects for the **Advanced .NET** course. The curriculum focuses on building data-driven web applications using the **Model-View-Controller (MVC)** pattern, **Entity Framework Core**, and robust **Identity** management.

## 🚀 Key Learning Areas

### 1. Data Management & Flow

* **Data Transfer:** Working with `ViewData`, `ViewBag`, `TempData`, and **Sessions**.
* **Model Binding:** Efficiently passing model data between Views and Controllers.
* **Form Handling:** Managing user input and complex data structures.

### 2. Data Persistence (EF Core)

* **Entity Framework Core:** Database-first and Code-first approaches.
* **Data Seeding:** Automatically populating databases with initial values.
* **Relationships:** Configuring 1:1, 1:N, and N:N relationships using Fluent API and Data Annotations.
* **Complex Models:** Building sophisticated data structures for real-world scenarios.

### 3. Validation & Security

* **Model Validation:** Server-side and client-side validation using attributes.
* **Authentication:** Implementing **ASP.NET Core Identity**.
* **Authorization:** Role-based access control (RBAC) to protect sensitive data and views.
* **Identity Scaffolding:** Customizing user models and registration flows.
